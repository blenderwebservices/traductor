## 1. Configuración de Empaquetado

Para compilar la aplicación y generar un instalador `.dmg` distribuible para macOS, se realizaron las siguientes integraciones:

1. **Instalación de `electron-builder`:**
   Se incorporó `electron-builder` como dependencia de desarrollo para compilar la aplicación, generar el bundle `.app` y crear la imagen de disco con compresión UDZO.
2. **Configuración en `package.json`:**
   Se definió la sección `"build"` especificando:
   - Identificador de la app: `com.astro.traductor`
   - Nombre de producto: `Astro`
   - Destino de salida: `release/`
   - Configuración visual de DMG: Enlace directo arrastrable hacia `/Applications`.
   - Inclusión de recursos nativos (`bin/cmd-tap-listener` y `bin/ocr-helper`) en `extraResources`.
3. **Resolución de Rutas de Binarios Nativos (`electron/main.js`):**
   Se implementó la función `getBinPath(name)` para que la aplicación localice los ejecutables Swift tanto en modo desarrollo como dentro del bundle empaquetado (`process.resourcesPath/bin`).

---

## 2. Comando de Compilación

Se añadió el script en `package.json`:
```bash
npm run dist:dmg
```
Este comando ejecuta en secuencia:
1. `npm run build:native`: Compila con `swiftc` los módulos nativos en `bin/`.
2. `npm run build:ui`: Empaqueta la interfaz de React Native con Vite en `dist/`.
3. `electron-builder --mac dmg`: Construye la app y genera el archivo DMG.
