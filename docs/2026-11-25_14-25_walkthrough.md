# Reporte de Entrega: Corrección de Cierre en Buscador de Voces

**Fecha y Hora:** 2026-11-25 14:25  
**Autor:** Antigravity Agent  

---

## 1. Causa Raíz Diagnosticada
En el componente `SettingsModal.tsx`, la ventana modal de selección de voces ("Voz para Texto de Origen" / "Voz para Texto de Destino") tenía el contenedor principal implementado como un `<TouchableOpacity style={styles.voicePickerOverlay} onPress={() => setVoicePickerTarget(null)}>`.

En React Native Web:
- Los componentes `<TextInput>` se renderizan como `<input>` HTML nativo y, por diseño, renuncian al responder lock de React Native para permitir la interacción nativa del cursor y selección de texto.
- Al hacer clic con el mouse en el input de búsqueda, el evento DOM `click` se propagaba hacia arriba hasta el `<TouchableOpacity>` padre que fungía de overlay.
- Esto disparaba inmediatamente `setVoicePickerTarget(null)` cerrando el modal.
- Al navegar con `Tab`, no se producía ningún evento de ratón, razón por la cual sí era posible enfocar el input y buscar.

---

## 2. Modificaciones Implementadas

1. **Desacoplamiento de Fondo (Backdrop) y Contenedor Modal:**
   - Se reemplazó el contenedor raíz de `TouchableOpacity` por un `<View style={styles.voicePickerOverlay}>`.
   - Se agregó un `<Pressable style={StyleSheet.absoluteFill} onPress={() => setVoicePickerTarget(null)} />` como elemento hermano (backdrop) detrás del cuadro de diálogo.
   - La caja del modal (`voicePickerBox`) ahora es un hermano independiente posicionado en capa superior con `zIndex: 10`.
   - Cualquier clic en el `<TextInput>` de búsqueda o en el contenido del diálogo ocurre dentro de `voicePickerBox` y físicamente nunca alcanza el evento del backdrop.

2. **Mejora de UX (Auto-Foco Inmediato):**
   - Se añadió `autoFocus={true}` al `<TextInput>` del buscador de voces para que al pulsar "Cambiar", el teclado quede listo para buscar de inmediato sin requerir un clic adicional.

3. **Homogeneización en Modales Relacionados:**
   - Se aplicó el mismo patrón de backdrop desacoplado con `Pressable` y `zIndex: 10` a la ventana principal de `SettingsModal`, `HistoryModal` y `LanguageBar` para garantizar total estabilidad frente a la propagación de clics en la web.
