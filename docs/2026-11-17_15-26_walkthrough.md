# Reporte de Entrega: Supresión de Advertencias EGL/GLDisplay al Iniciar

**Fecha:** 2026-11-17 15:26  
**Estado:** Resuelto y Verificado  

---

## 1. Causa del Mensaje

Al iniciar la aplicación, Chromium generaba los siguientes mensajes en consola:
```
ERROR:ui/gl/gl_display.cc:648] Initialization of all (1) EGL display types failed.
ERROR:ui/gl/init/gl_initializer_mac.cc:127] GLDisplayEGL::Initialize failed.
ERROR:components/viz/service/main/viz_main_impl.cc:192] Exiting GPU process due to errors during initialization
```

### Explicación Técnica:
Chromium en macOS realiza un sondeo inicial intentando utilizar controladores de visualización EGL/ANGLE antes de recurrir al motor nativo de Metal/AppKit de macOS. Aunque este mensaje es inocuo para el funcionamiento de la aplicación (Electron realiza el fallback automáticamente), genera ruido visual y falsas alarmas de fallo en el terminal.

---

## 2. Solución Aplicada

1. **Configuración de Switches de Chromium en `electron/main.js`:**
   Se agregaron switches a nivel de línea de comandos de Electron antes de inicializar la app para suprimir los logs de depuración interna del motor C++ de Chromium:
   ```javascript
   app.commandLine.appendSwitch('log-level', '3');
   app.commandLine.appendSwitch('disable-logging');
   ```

2. **Ajuste en el Lanzador `electron/start.js`:**
   - Se añadió el flag `--log-level=3` a los argumentos de arranque de Electron.
   - Se configuró un filtro en el flujo `stderr` del subproceso para descartar trazas de advertencia internas de `gl_display.cc`, `gl_initializer_mac.cc` y `viz_main_impl.cc`, preservando de forma íntegra cualquier error real de Node.js o JavaScript de la aplicación.
