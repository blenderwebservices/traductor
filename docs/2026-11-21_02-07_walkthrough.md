# Walkthrough: Fix Definitivo de Altura y Borde Inferior

**Fecha:** 2026-11-21 02:07

## Causa Raíz
`AppRegistry.runApplication` de `react-native-web` envuelve `<App />` en un `AppContainer` con `flex: 1` dentro de `#root`. Como `#root` en [`index.html`](file:///Users/franciscogomezbarragan/Herd/traductor/index.html#L19-L24) era `display: block`, el `flex: 1` del `AppContainer` no tenía efecto y `height: 100%` en los hijos se resolvía como `height: auto`, haciendo crecer el contenedor más allá de los `480px` de la ventana y recortando el borde inferior y el footer.

## Solución
- [`index.html`](file:///Users/franciscogomezbarragan/Herd/traductor/index.html#L19-L24): `#root` ahora usa `display: flex; flex-direction: column; height: 100vh; width: 100vw;`.
- [`src/App.tsx`](file:///Users/franciscogomezbarragan/Herd/traductor/src/App.tsx#L34-L45): `styles.root` fijado con `position: 'absolute'`, `top: 0, left: 0, right: 0, bottom: 0` y `padding: 8`, garantizando un bounding box exacto de `100vw x 100vh`.
- [`src/components/TranslatorModal.tsx`](file:///Users/franciscogomezbarragan/Herd/traductor/src/components/TranslatorModal.tsx#L652-L659): `scrollArea` usa `flex: 1, flexShrink: 1, flexBasis: 0, minHeight: 0` para forzar el scroll interno sin expandir el borde inferior.
