# Scratchpad y Checklist de Desarrollo: Astro Traductor

**Fecha:** 2026-11-17 14:10  
**Estado:** Completado con éxito  

## Checklist de Requerimientos

### 1. Requerimientos Funcionales Principales
- [x] Activación Global:
  - [x] Atajo `Cmd + Alt + D` registrado globalmente en macOS (`globalShortcut`).
  - [x] Hook de teclado para doble pulsación rápida de la tecla Command (`Cmd + Cmd`) implementado en Swift nativo (`native/cmd-tap-listener.swift`).
  - [x] Validación y petición de permisos de accesibilidad en macOS (`systemPreferences.isTrustedAccessibilityClient`).
- [x] Captura Automática de Texto:
  - [x] Lectura de selección activa de la app en foco al activarse (`osascript` keystroke simulation).
  - [x] Fallback al portapapeles si no hay texto seleccionado.
  - [x] Autocompletado inmediato e inicio instantáneo de traducción en streaming.
- [x] Lógica de Idiomas Inteligente:
  - [x] Detección automática del idioma de origen mediante IA / heurística rápida.
  - [x] Idioma de destino predeterminado: Español.
  - [x] Regla condicional: Si el origen es Español, destino conmuta automáticamente a Inglés (`es` -> `en`).
- [x] Configuración y Ajustes:
  - [x] Botón de ajustes visible y accesible en el modal (`SettingsModal.tsx`).
  - [x] Capacidad de fijar idiomas de destino diferentes (botón Pin 📍).
  - [x] Selectores rápidos para invertir idiomas (`Swap ⇄`) o elegir manualmente.

### 2. Características Deseables (Nice-to-Have)
- [x] Reemplazo en Línea (Auto-Replace):
  - [x] Atajo rápido `Cmd + Enter` o botón de reemplazo.
  - [x] Reemplazo del texto original seleccionado en la app de fondo con la traducción (clipboard + keystroke Cmd+V).
- [x] Ajuste de Tono (Contexto IA):
  - [x] Botones de tono: Estándar, Formal, Informal, Técnico, Resumido (`TonePicker.tsx`).
- [x] Modo Diccionario Extendido:
  - [x] Detección de entrada de una sola palabra.
  - [x] Despliegue de categoría gramatical, fonética, definición y ejemplos de uso (`DictionaryCard.tsx`).
- [x] Reconocimiento de Texto en Pantalla (OCR):
  - [x] Atajo `Cmd + Alt + O` y botón de captura de área en pantalla (`screencapture -i`).
  - [x] Extracción de texto con Apple Vision Framework nativo (`native/ocr-helper.swift`).
  - [x] Carga inmediata del texto reconocido en el modal.
- [x] Síntesis de Voz (Text-to-Speech):
  - [x] Botón de audio para reproducir pronunciación del texto de origen.
  - [x] Botón de audio para reproducir la traducción generada (macOS `say` / Web Speech).
- [x] Historial y Favoritos:
  - [x] Registro local persistente de traducciones (`storageService.ts`).
  - [x] Marcado de favoritas (⭐) y búsqueda en historial (`HistoryModal.tsx`).
- [x] Mejora de Redacción (Proofreading):
  - [x] Detección cuando origen y destino coinciden (ej. Español -> Español).
  - [x] Modo de corrección ortográfica, gramatical y sugerencias de estilo (`ProofreadingCard.tsx`).

### 3. Requerimientos No Funcionales
- [x] Baja Latencia:
  - [x] Modal renderizado en <200ms (pre-renderizado en ventana oculta con invocación instantánea <20ms).
  - [x] Respuestas mostradas mediante streaming token por token (~16ms por token).
- [x] Comportamiento de Ventana Efímera:
  - [x] Cierre/ocultamiento al hacer clic fuera (`blur`) o presionar `Esc`.
  - [x] Proceso liviano en segundo plano con icono en la barra de menú (tray).
- [x] Adaptabilidad Visual:
  - [x] Soporte automático para Modo Oscuro y Modo Claro según macOS.
  - [x] Estilo minimalista Spotlight / Raycast con bordes suaves, translucidez y acrylic blur.
