## 1. Causa Raíz y Solución de Permisos de Accesibilidad al Reinstalar

### Diagnóstico
En macOS, el sistema de seguridad y privacidad (TCC) almacena los permisos de accesibilidad basándose en la identidad del código (`Designated Requirement`).
- Cuando una aplicación Electron se compila sin firma Developer ID o con firma ad-hoc por defecto, macOS genera un requisito designado vinculado estrictamente al hash del binario (`designated => cdhash H"..."`).
- Cada vez que se compila una nueva versión, se reinstala la app o se instala una versión anterior sobre `/Applications/Astro.app`, el hash binario cambia. Como resultado, macOS TCC detecta que el binario no coincide con el `cdhash` autorizado y revoca/ignora los permisos, obligando al usuario a quitar y volver a poner la app en Ajustes del Sistema.

### Solución Implementada
1. **Requisito Designado Explícito por Bundle ID (`com.astro.traductor`):**
   - Se creó el script `scripts/after-pack.js`, integrado en el ciclo de vida `afterPack` de `electron-builder`.
   - Firma tanto `Astro.app` como los binarios auxiliares (`cmd-tap-listener` y `ocr-helper`) con:
     `-r='designated => identifier "com.astro.traductor"'`
   - Esto indica a macOS que cualquier versión instalada que posea el identificador de bundle `com.astro.traductor` es la misma aplicación legítima, preservando los permisos de eventos de teclado de forma persistente.
2. **Sondeo Reactivo de Accesibilidad (`electron/main.js`):**
   - Se añadió un monitor en segundo plano (`startAccessibilityMonitor`) que detecta cada 2 segundos si el permiso fue concedido en Ajustes del Sistema.
   - Al detectarlo, inicia inmediatamente `cmd-tap-listener` y notifica a la interfaz de usuario en tiempo real sin requerir reinicio.
   - Apertura directa del panel de Accesibilidad mediante `x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility`.

## 2. Marca de Versión de Compilación en los Ajustes

1. **Inyección en Tiempo de Compilación (`vite.config.mts`):**
   - Se definieron las constantes globales `__APP_BUILD_TIMESTAMP__` y `__APP_BUILD_DATE__`.
   - Si se compila mediante `scripts/build-dmg.sh`, toma exactamente la variable de entorno `BUILD_TIMESTAMP` (ej. `2026.11.26.0950`), garantizando coincidencia absoluta entre el nombre del archivo DMG y la versión mostrada.
2. **Visualización en `SettingsModal.tsx`:**
   - **Encabezado:** Badge `v1.0.YYYY.MM.DD.HHMM` al lado de "Configuración de Astro".
   - **Pie de ventana:** Texto `Compilación: YYYY-MM-DD HH:mm` en la esquina inferior izquierda.
   - **Tarjeta de Accesibilidad:** Indicador `ID: com.astro.traductor` con estado de vinculación claro para el usuario.
